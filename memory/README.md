# Memory Module Documentation

The memory module provides functionality for managing research sessions, evidence storage, and report generation.

## Modules

### `save_report.py`

High-quality markdown report generation with comprehensive type hints and security features.

**Key Features:**
- Rich markdown report generation
- Evidence tracking from documents and web results
- Verification status reporting
- Security sanitization and validation
- Flexible configuration with `ReportConfig`

**Main Functions:**
- `save_report()` - Save a research report to markdown
- `build_enriched_markdown()` - Build markdown without saving
- `get_reports_directory()` - Get reports directory path
- `get_latest_report()` - Get most recent report
- `get_reports_by_session()` - Get reports for a session
- `get_reports_by_date_range()` - Get reports by date range
- `get_report_statistics()` - Get report statistics

**Configuration:**
```python
config = ReportConfig.strict()  # Security-sensitive
config = ReportConfig.default()  # Standard
```

**Report Structure:**
```markdown
# Research Report

**Query:** Your query
**Date:** 2024-01-15 14:30:22 UTC
**Session ID:** session_123
**Generated:** 2024-01-15T14:30:22+00:00

---

## Executive Summary

Main content...

---

## Supporting Evidence

### Document Evidence

### Web Evidence

### Verification Summary

---

## Verification Output

---

*This report was automatically generated by the AI Research Orchestrator.*
```

### `memory.py`

Core memory management for research sessions.

**Key Functions:**
- `init_memory()` - Initialize memory system
- `save_evidence()` - Save evidence for a session
- `save_last_user_query()` - Save user query for follow-ups
- `build_evidence_context()` - Build evidence context from JSON
- `get_session_context()` - Get session context for follow-ups
- `clear_session()` - Clear session memory

### `helpers.py`

Helper functions for research operations.

**Key Functions:**
- Session management
- Evidence processing
- State management

### `logger.py`

Logging configuration for the memory module.

## Usage

### Saving Reports

```python
from memory.save_report import save_report, ReportConfig

# Basic report
filepath = save_report(
    content="Research findings...",
    query="What are transformer models?"
)

# Report with evidence
state = {
    "evidence_json": json.dumps({
        "document_evidence": {...},
        "web_evidence": {...}
    }),
    "verification": "...",
    "verification_status": {...}
}

config = ReportConfig.strict()
filepath = save_report(
    content="Final answer...",
    query="Query",
    state=state,
    config=config
)
```

### Report Discovery

```python
from memory.save_report import (
    get_latest_report,
    get_reports_by_session,
    get_report_statistics
)

# Get latest report
latest = get_latest_report()

# Get reports for a session
session_reports = get_reports_by_session("session_123")

# Get statistics
stats = get_report_statistics()
```

### Session Management

```python
from memory import (
    init_memory,
    save_evidence,
    save_last_user_query,
    get_session_context,
    clear_session
)

# Initialize
init_memory()

# Save evidence
save_evidence(session_id, query, evidence_json)

# Get session context
context = get_session_context(session_id)

# Clear session
clear_session(session_id)
```

## Report Integration

The memory module integrates with the orchestrator to generate rich reports:

```python
# Orchestrator calls save_report with full state
result = orchestrator_agent(query, session_id=session_id)
saved_path = save_report(
    content=result["final_answer"],
    query=query,
    state=result,  # Full orchestration state
    config=ReportConfig.strict()
)
```

## Best Practices

1. Always pass full orchestration state to `save_report()`
2. Use `ReportConfig.strict()` for security-sensitive applications
3. Enable debug mode during development
4. Check verification status before using reports
5. Monitor evidence gaps for incomplete research
6. Use session IDs for tracking related reports
7. Regularly review report statistics

## Troubleshooting

### No Evidence Found

Check `evidence_json` in the state dictionary.

### Low Confidence

Review `verification_status.gaps` and re-retrieve evidence.

### Large Reports

Use `ReportConfig.strict()` for security-sensitive applications.
